# Bundled font notice

NotoSansThai-Regular.otf is the unmodified upstream **full static Regular** font,
name-table version `2.002`, not a variable font.
Its full cmap covers Thai and Latin so mixed detail lines do not invoke a
system font. Unsupported characters produce a visible error indicator.
